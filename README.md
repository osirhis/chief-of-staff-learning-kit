# Chief of Staff Learning Kit

Piloto pessoal para a mentoria de Chief of Staff: duas skills para capturar fricções e conduzir uma governança sob demanda, preservando o julgamento humano.

## O que inclui

- `registrar-friccao`: cria ou atualiza o registro canônico de algo que não ocorreu como esperado.
- `governar-friccoes`: prepara uma pauta priorizada de reflexão, opções e recomendações; não executa alterações sem confirmação explícita.

Os dados ficam no diretório local de cada pessoa, em `friccoes/`. Este projeto não centraliza conteúdo pessoal nem altera o `AGENTS.md` de ninguém.

## Princípios do piloto

- Uma fricção pode ter resoluções diferentes: tool, configuração, skill, contexto, decisão, propósito/mandato, experimento ou nenhuma mudança.
- A governança indica os primitivos que provavelmente precisam ser observados na correção. Uma fricção pode envolver vários primitivos; a indicação não é um diagnóstico fechado.
- Novo sintoma de problema conhecido atualiza a fricção canônica; não cria duplicata.
- Governança acontece sob demanda.
- Jurisprudência é o histórico revisável das decisões já tomadas, preservado inicialmente na própria fricção.

## Instalação para teste local

No Codex, adicione a pasta deste repositório como marketplace local e instale o plugin `chief-of-staff-learning-kit`. Depois, em um projeto de teste, peça ao CoS para registrar uma fricção e, em seguida, chame a governança.

O caminho exato de instalação será validado no piloto antes de ser recomendado à turma.
